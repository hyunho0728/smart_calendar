# 새로운 환경에서 작업하려면
1. 해당 환경에서 git과 python (3.14.0)[중요! Add Python to PATH 무조건 체크] 설치
2. 원하는 폴더에서 우클릭 -> Open Git Bash here
3. 아래 명령어들 입력
4. git clone https://github.com/hyunho0728/smart_calendar.git
5. cd smart_calendar
6. python -m venv .venv
7. source .venv/Sripts/activate
8. (가상환경 켜지는지 확인)
9. pip install -r requirements.txt
10. python calendar/app.py
